# IMA 知识库上传指南

## 已准备的资料文件

1. **books_list.md** — 完整的书籍清单（Markdown 表格 + 详细介绍）
2. **books_data.json** — 结构化 JSON 数据，便于二次处理/导入
3. **bookshelf.html + books.js** — 复刻视频风格的图书展示网站

## 上传至 ima 知识库「图书知识库」步骤

1. 打开 ima.copilot（腾讯 ima）客户端或网页版，登录你的账号。
2. 进入「知识库」→ 找到或新建「图书知识库」。
3. 点击「上传文件」/「导入」。
4. 选择本目录下的 `books_list.md` 与 `books_data.json`。
5. 等待解析完成后，即可在 ima 中按书名、作者、出版社等字段检索。

## 注意事项

- 由于当前环境无法直接访问你的 ima 账号，需手动完成上传。
- 如需更细粒度的条目（每本书一条），可将 `books_data.json` 中的对象批量导入支持 JSON 的知识库，或在 ima 中逐条新建卡片。
- 封面的豆瓣外链在 ima 中可能需要联网才能显示；如需离线使用，可将封面图片批量下载后作为附件上传。
